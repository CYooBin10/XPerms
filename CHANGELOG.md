# Changelog

## 2.0.0

- Added schema v2 storage with migration from legacy/schema v1 data, identity maps, atomic writes, backup creation, and backup recovery.
- Added deterministic resolver with direct boolean nodes, multi-group membership, inheritance, wildcard matching, contexts, priorities, weights, traces, and caching.
- Added user/group/explain command paths, default-group commands, temporary-node cleanup core API, player context refreshes, and PlaceholderAPI permission/context placeholders.
- Kept JSON storage; no Form UI, audit/rollback, tracks/meta UI, or database backend.
